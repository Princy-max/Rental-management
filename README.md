TITLE:
PS43 – Vehicle Rental Management System
PROBLEM STATEMENT AND PROBLEM DESCRIPTION:
Create a vehicle rental system for managing vehicles, customers, bookings and rental status. Cus-
tomers should be able to view available vehicles and request a rental for a selected period. The
system should check vehicle availability before confirming a booking. Rental staff should be able to
manage bookings and update the vehicle’s rental status.
Core Requirements
• Administrators can add and manage vehicle records.
• Vehicles should include useful information such as type, model and availability.
• Customers can view available vehicles.
• Customers can request or create rental bookings.
• The system should prevent overlapping rentals for the same vehicle.
• Staff can update rental status such as Booked, Active, Returned or Cancelled.
• Returned vehicles should become available again when appropriate.
